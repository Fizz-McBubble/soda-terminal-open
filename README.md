# Soda Terminal

This source release carries forward Soda Terminal’s existing algorithm, UI, saved-account semantics, and release checks. The calculation carrier runs in the browser; this is not a new product implementation. Install with `pnpm install --frozen-lockfile`, then run `pnpm source:check`, `pnpm typecheck`, `pnpm test`, and `pnpm build`. The build checks every source pin before starting, verifies the approved media inventory, and emits an offline manifest.

After editing this public source release, review your diff and run the affected checks first. Then explicitly run `pnpm source:refresh` to refresh SOURCE-MANIFEST.json and derive a new release identity; build never refreshes it automatically. Name newly added or deliberately removed release files with `pnpm source:refresh --add src/path/to/new.ts --remove src/path/to/retired.ts`. Only public release paths are accepted, and a missing pinned file is an error until explicitly removed. Review and commit the refreshed manifest together with your source changes, then run `pnpm source:check` and `pnpm build`. The identity is a content pin, not proof of maintainer review, media licensing, or correctness; media clearance must be updated separately when changing media.

`deploy/cloudflare/prepare.mjs` checks the built Static Assets candidate; the Scanner download manifest remains pinned and must be updated and verified for each Scanner release.
